Overview
--------

This project pads nucleotide sequences.

Installation
------------

To install ``seqpad``, you can use ``pip``.
Open your terminal and run:

.. code-block:: shell

    pip install seqpad

Typing
------

The typing conforms strictly to ``mypy``.

.. container:: versionadded

    **Added in version 1.1.**

``seqpad.core``
~~~~~~~~~~~~~~~

The functions in ``seqpad.core`` can also be imported from ``seqpad`` directly.

``seqpad.core.main(args: Iterable[int] | None = None) -> int``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

The project also provides a CLI that can also be accessed from within Python.
For more information, read the help message that can be accessed through one of the two following ways.

.. code-block:: shell

    # bash
    python3 -m seqpad -h

.. code-block:: python

    # python
    import seqpad
    seqpad.main(['-h'])

.. container:: versionadded

``seqpad.core.seqpad[Seq: SizedAndSupportsAdd[str]](seq: Seq) -> Seq``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

The core function of this project is implemented as follows:

.. code-block:: python

    def seqpad(seq: Seq) -> Seq:
        while len(seq) % 3 != 0:
            seq = seq + "N"
        return seq
